- [index.html](index.html): self-contained presentation, including the main Space Mono fonts and media. Open in a browser; no server is required.
- [presentation_draft.pdf](presentation_draft.pdf): original presentation draft.
- [poster_inkscape.svgz](poster_inkscape.svgz): editable Inkscape publication artwork.

This activity is a reference for [year_1](../../.agents/skills/html-slides/references/year_1.md): Space Mono, tactile graphic imagery, and the green/cyan/violet activity palette. This palette is one application of year_1, not a requirement for other topics.

Install **Space Mono Regular (400) and Bold (700)** before editing SVG/SVGZ text in Inkscape. Download from [Google Fonts](https://fonts.google.com/specimen/Space+Mono), or use the licensed [local font resources](../../.agents/skills/html-slides/assets/fonts/year_1/), including OFL. The editable artwork references the family and does not embed the font files. HTML font embedding does not install fonts for Inkscape.

For Russian or mixed-script revisions, use `'Space Mono', monospace` and inspect Cyrillic fallback on the target computer: missing glyphs use the system monospace font and can look or wrap differently. Preserve editable text originals when exporting outlined artwork.
